## Claim boundary

The public repository demonstrates a working MVP, synthetic demo, automated
tests, CI, and a versioned benchmark. Those technical artifacts are not external
customer evidence. The main README, product case, release notes, profile, and
resume must not claim external validation or measured outcomes unless future
research supports them.
